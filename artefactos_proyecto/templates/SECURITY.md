## Reportar una vulnerabilidad

**No abras un issue público** para vulnerabilidades. Repórtala en privado por:

- Email: CAMBIAR_EMAIL_DE_CONTACTO, o
- GitHub → pestaña **Security** → **Report a vulnerability** (Security Advisories).

Incluye: descripción, pasos para reproducir, impacto y versión afectada.

## Qué esperar

- Confirmación de recepción en un plazo razonable.
- Coordinación de un arreglo y divulgación responsable antes de hacerlo público.
