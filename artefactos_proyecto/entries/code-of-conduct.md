# CODE_OF_CONDUCT.md

## Qué es

Documento que establece las normas de comportamiento esperadas en la comunidad del
proyecto y el canal para reportar abusos. El estándar de facto es el
[Contributor Covenant](https://www.contributor-covenant.org). GitHub lo reconoce y lo
enlaza en la pestaña Community.

## Cuándo SÍ aplica

- Proyecto público con comunidad, issues o PRs de terceros.

## Cuándo NO aplica

- Repo personal privado sin colaboradores.

## Cómo usarlo

Copiar `templates/CODE_OF_CONDUCT.md` (Contributor Covenant abreviado) y poner un
**contacto real** para reportes. Es el mismo enfoque que usa Prowler.
