# README.md

## Qué es

La portada del repo: qué es, para qué sirve, cómo instalar, cómo usar y cómo contribuir
(o enlace a `CONTRIBUTING.md`). GitHub lo renderiza como página principal. Es lo primero
que lee un humano o un LLM para entender el proyecto.

## Cuándo SÍ aplica

- Todo repo, sin excepción. Créalo al iniciar el proyecto.

## Cuándo NO aplica

- Ninguno.

## Cómo usarlo

Copiar `templates/README.md` y rellenar secciones: título, descripción de una línea,
requisitos, instalación, uso, y enlaces (LICENSE, CONTRIBUTING, docs). Ajustar la
profundidad al tamaño del proyecto.
